# 上下文整理：期限、进度与失败恢复

自动整理、`/compact`、指定范围整理、compress 工具和溢出恢复共用一次整理
操作的 **300 秒总预算**。准备、等待执行权、重规划、分块摘要和最终合并均
计入预算，嵌套调用不重新计时。正常模型回答保留自己的回合上下文。

非空正文和推理增量算有效输出；心跳、空行、角色和 usage 不算。连续 60 秒
没有有效输出时显示“仍在等待模型输出”，但不提前终止。总期限到达后取消
生成，不再启动后续摘要或安装新的候选。摘要仍完整缓冲，局部正文和推理不
进入聊天记录；摘要中的工具调用只统计诊断信息，不执行。

## 失败、保存与聊天记录

- 自动整理失败，但仍低于安全发送边界：保留最近有效投影，按原防重复整理
  逻辑继续本轮。
- 已达硬上限或供应商已确认溢出：结束本次执行，返回保留具体原因的
  `ErrCompactionRequired`，等待用户操作。
- 空摘要、不减小的候选、固定前缀过大、没有可压缩区域：同样不再触发自动
  有损截断。旧的 `truncate` 回执仍能读取。
- 取消或到期先于提交边界：拒绝安装摘要。提交已开始：完成当前批的一致性
  和持久化处理，界面显示“正在保存”，随后不启动新的批次。
- 前一批摘要或原有工具结果裁剪已提交：保留这些结果；后续失败如实报告
  `applied=true`，不宣称整次操作完全没有变化。
- 保存失败沿用恢复屏障；摘要缓冲工作线程退出前不释放执行权。忽略取消的
  适配器不会得到后台游离写入者，原有停止宽限与恢复所有权仍保留。

原始聊天记录与发送给模型的投影分开。本次不修改历史分页，不因整理超时
删除原文、消息 ID 或顺序；独立的历史显示问题仍需单独复现。

## 卡片、切换、重连与重试

卡片区分准备、等待响应、生成和保存；只显示已等待秒数及已完成分块数量，
不显示无法证明的百分比。阶段变化和终态立即发布，连续输出最多每秒更新
一次，计时只更新卡片本身。中间状态保存在运行态，不逐秒写入会话日志。

手动整理沿用原维护卡片；自动整理仍属于原回合。终态回执持久化为不进入
模型上下文的可选诊断记录，并在运行态检查点保留最新终态。切换和重连通过
会话绑定、运行 ID、epoch 和 revision 恢复；迟到事件不能打开已结束的卡片。
没有活动所有者的旧进行中卡片显示“已中断”。重启后的失败回执绑定新的
运行态身份，支持重新校验后重试。

“重试整理”仅调用该会话的整理接口，服务端校验当前运行 ID、epoch、写权限
和执行所有权。多个窗口的重复点击不会并行启动整理。不重新提交原消息、
不自动继续原任务、不重跑工具；成功后由用户继续对话。保存恢复异常使用
已有恢复入口，不显示普通整理重试。

旧服务缺少新增进度时沿用原展示，不虚构其支持五分钟期限。新增字段可选，
未知或损坏字段安全忽略，原协议握手和契约摘要校验保持有效。

## 协议和排障字段

新增事件 `context_compaction_progress` 追加在原枚举后。同一可选对象
`contextCompaction` 同时用于事件、运行态快照和维护回执：

| 字段 | 含义 |
| --- | --- |
| `runId` / `parentOperationId` | 整理操作及可选手动维护操作身份 |
| `turnId` / `runtimeEpoch` / `revision` | 回合、运行代次、同一操作内递增版本 |
| `trigger` / `phase` / `status` | 来源、准备/等待/生成/保存阶段、运行或终态 |
| `startedAt` / `deadlineAt` / `observedAt` / `lastOutputAt` | Unix 毫秒时间；末次有效输出时间可缺省 |
| `requests` / `completedParts` / `totalParts` | 请求及分块数量 |
| `errorCode` / `applied` / `retryable` | 失败原因、是否已有提交、是否可重试 |

可用 `errors.As` 识别 `SummaryError`：`summary_budget_exceeded`、
`summary_provider_error`、`summary_empty`、`summary_output_truncated`、
`summary_no_reduction`、`summary_context_changed`。用户停止仍为取消，保存
错误不归类为供应商失败。

日志记录操作耗时、请求数、分块数、失败码及末次有效输出时间；请求调试日志
记录耗时和工具调用片段数。复用传输观察器查看连接、响应头、首包、累计
字节和结束阶段，新增观察器不覆盖原诊断观察器。网络字节包含心跳，不能
视为有效模型输出。进度不包含摘要、推理正文、凭据或完整请求。

## 验证方式和边界

Go 确定性虚拟时间测试覆盖无输出、持续慢输出、共享预算、排队停止、提交
竞态、部分成功与迟到输出。Controller 覆盖会话切换、回执恢复和重试准入；
Provider 覆盖缓冲前观察及原传输观察器保留。成功请求的缓存形状、摘要提示词、
工具 schema、消息顺序和请求参数保持原行为。

分别执行根 Go 与 Desktop 模块测试、定向 race、`repolint`、前端类型检查、
transcript 测试和维护浏览器测试。原生脚本
`desktop/packaging/compaction-native-smoke.mjs` 使用实际 macOS Electron 包、
隔离 Reasonix home 和本地可控 SSE 服务；真实等待生产环境 300 秒，验证停止、
持续心跳超时、切换、原文和草稿保留、重启、仅整理重试及正常进程退出。脚本
不绕过包身份握手，也不替换包内二进制。

本地 fixture、原生包和真实供应商验证必须分开报告。上述测试不能证明所有
推理模型都能在五分钟内成功生成长上下文摘要。本次不包含发布。
